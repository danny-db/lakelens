# Unit economics from system tables

Generated by `tools/gen_unit_economics_skill.py` from the LakeLens Unit economics board (`app/boards.py`). Edit the board and regenerate; do not edit this file by hand.

Every query reads only `system.billing`, `system.query`, `system.access` and `system.storage` tables, so it runs in any account that has system tables enabled. Each figure uses the account's price from `system.billing.account_prices` where one is set for the SKU, and list price otherwise.

## Step 1. Anchor the window

The window holds full days only. Billing writes most of a day's records that day and the rest the next day, so each query ends its window on the newest usage day whose usage runs to midnight and whose next-day records have landed, and otherwise the day before (the `latest`, `newest`, `bounds` and `win` CTEs). It uses those same dates for billing `usage_date`, query history `start_time`, audit `event_date` and storage `snapshot_date`. Do not use `current_date()` as the end: partial days make every unit cost look cheaper.

## Step 2. Run the queries

### Query 1. Unit economics (28 days)

The headline unit costs, then the raw inputs they are built from, over one window of full days. Each figure uses your account price where one is set and list price otherwise. Coverage says which workspaces each figure rests on. Hover or tap ⓘ for a definition.

Billing sees every workspace, but query history and audit only list the workspaces they cover, so each ratio divides only the spend of the workspaces its denominator can see. User counts are approximate (approx_count_distinct). Data under management is active table data from system.storage.table_metrics_history, which lists the tables in this region's metastore.

```sql
WITH latest AS (   -- the newest ingestion day; billing is still writing to it
  SELECT max(ingestion_date) AS day FROM system.billing.usage WHERE usage_date >= current_date() - INTERVAL 7 DAYS
),
newest AS (   -- the usage day before it: full once its usage runs to midnight and its next-day records have landed
  SELECT max(u.usage_end_time) AS last_end, count(CASE WHEN u.ingestion_date = l.day THEN 1 END) AS next_day_records
  FROM system.billing.usage u CROSS JOIN latest l
  WHERE u.usage_date = (SELECT date_sub(day, 1) FROM latest)
),
bounds AS (
  SELECT CASE WHEN n.last_end >= l.day AND n.next_day_records > 0 THEN date_sub(l.day, 1)
              ELSE date_sub(l.day, 2) END AS end_date
  FROM latest l CROSS JOIN newest n
),
win AS (SELECT date_sub(end_date, 27) AS start_date, end_date FROM bounds),
account_prices AS (
  SELECT sku_name, cloud, currency_code, usage_unit, price_start_time, price_end_time,
         pricing.default AS unit_price
  FROM system.billing.account_prices
),
priced AS (
  SELECT u.workspace_id, u.billing_origin_product AS product,
         datediff(w.end_date, u.usage_date) AS days_back,
         u.product_features.is_serverless AS is_serverless,
         u.product_features.sql_tier AS sql_tier,
         u.usage_quantity * lp.pricing.effective_list.default AS list_usd,
         u.usage_quantity * ap.unit_price AS acct_usd
  FROM system.billing.usage u
  CROSS JOIN win w
  LEFT JOIN system.billing.list_prices lp
    ON u.sku_name = lp.sku_name AND u.cloud = lp.cloud AND u.usage_unit = lp.usage_unit
   AND u.usage_start_time >= lp.price_start_time
   AND (lp.price_end_time IS NULL OR u.usage_start_time < lp.price_end_time)
  LEFT JOIN account_prices ap
    ON u.sku_name = ap.sku_name AND u.cloud = ap.cloud AND u.usage_unit = ap.usage_unit
   AND ap.currency_code = lp.currency_code
   AND u.usage_start_time >= ap.price_start_time
   AND (ap.price_end_time IS NULL OR u.usage_start_time < ap.price_end_time)
  WHERE u.usage_date BETWEEN (SELECT start_date FROM win) AND (SELECT end_date FROM win)
),
queries AS (   -- finished queries per workspace and day; read_bytes summed as DOUBLE (the BIGINT sum overflows)
  SELECT q.workspace_id, datediff(w.end_date, to_date(q.start_time)) AS days_back,
         count(*) AS queries, sum(CAST(q.read_bytes AS DOUBLE)) AS read_bytes,
         count(q.compute.warehouse_id) AS sql_queries,
         sum(CASE WHEN q.compute.warehouse_id IS NOT NULL THEN CAST(q.read_bytes AS DOUBLE) END) AS sql_read_bytes
  FROM system.query.history q CROSS JOIN win w
  WHERE q.execution_status = 'FINISHED'
    AND q.start_time >= (SELECT start_date FROM win) AND q.start_time < (SELECT date_add(end_date, 1) FROM win)
  GROUP BY 1, 2
),
ids AS (   -- each audit identity once per workspace and day; an email is a person, a UUID a service principal
  SELECT a.workspace_id, datediff(w.end_date, a.event_date) AS days_back, a.user_identity.email AS identity
  FROM system.access.audit a CROSS JOIN win w
  WHERE a.event_date BETWEEN (SELECT start_date FROM win) AND (SELECT end_date FROM win)
    AND a.user_identity.email IS NOT NULL
  GROUP BY 1, 2, 3
),
stored AS (   -- each table at its newest snapshot in the window, unless dropped by its end
  SELECT count(*) AS tables, sum(active_bytes) / POW(1024, 4) AS tib
  FROM (SELECT active_bytes, table_dropped_time FROM system.storage.table_metrics_history
        WHERE snapshot_date BETWEEN (SELECT start_date FROM win) AND (SELECT end_date FROM win)
        QUALIFY row_number() OVER (PARTITION BY table_id ORDER BY snapshot_date DESC) = 1)
  WHERE table_dropped_time IS NULL OR to_date(table_dropped_time) > (SELECT end_date FROM win)
),
spend AS (   -- per workspace
  SELECT workspace_id,
         sum(list_usd) AS list_usd,
         sum(coalesce(acct_usd, list_usd)) AS net_usd,
         sum(CASE WHEN acct_usd IS NOT NULL THEN list_usd END) AS priced_list_usd,
         sum(acct_usd) AS priced_acct_usd,
         count(CASE WHEN acct_usd IS NULL AND list_usd > 0 THEN 1 END) AS unpriced_rows,
         sum(CASE WHEN floor(days_back / 7) = 0 THEN coalesce(acct_usd, list_usd) END) AS week_net_usd,
         collect_set(CASE WHEN list_usd > 0 THEN product END) AS products
  FROM priced GROUP BY 1
),
q AS (   -- per workspace
  SELECT workspace_id, sum(queries) AS queries, sum(read_bytes) AS read_bytes,
         sum(sql_queries) AS sql_queries, sum(sql_read_bytes) AS sql_read_bytes
  FROM queries GROUP BY 1
),
users AS (
  SELECT approx_count_distinct(identity) AS mau,
         approx_count_distinct(CASE WHEN identity LIKE '%@%' THEN identity END) AS mau_human,
         approx_count_distinct(CASE WHEN floor(days_back / 7) = 0 THEN identity END) AS wau,
         approx_count_distinct(CASE WHEN days_back = 0 THEN identity END) AS dau,
         collect_set(workspace_id) AS audit_workspaces
  FROM ids
),
m AS (   -- one row; each ratio's spend is limited to the workspaces its denominator can see
  SELECT max(w.start_date) AS start_date, max(w.end_date) AS end_date,
         sum(s.list_usd) AS list_usd, sum(s.net_usd) AS net_usd,
         sum(s.priced_list_usd) AS priced_list_usd, sum(s.priced_acct_usd) AS priced_acct_usd,
         sum(s.unpriced_rows) AS unpriced_rows,
         count(CASE WHEN s.list_usd > 0 THEN 1 END) AS workspaces,
         size(array_distinct(flatten(collect_list(s.products)))) AS products,
         sum(s.week_net_usd) / 7 AS daily_net_usd,
         sum(q.queries) AS queries, sum(q.read_bytes) / POW(1024, 4) AS read_tib,
         count(q.workspace_id) AS q_workspaces,
         sum(CASE WHEN q.queries > 0 THEN s.list_usd END) AS q_list_usd,
         sum(CASE WHEN q.queries > 0 THEN s.net_usd END) AS q_net_usd,
         sum(q.sql_queries) AS sql_queries, sum(q.sql_read_bytes) / POW(1024, 4) AS sql_read_tib,
         count(CASE WHEN q.sql_queries > 0 THEN 1 END) AS sql_workspaces,
         max(u.mau) AS mau, max(u.mau_human) AS mau_human, max(u.wau) AS wau, max(u.dau) AS dau,
         max(size(u.audit_workspaces)) AS a_workspaces,
         sum(CASE WHEN array_contains(u.audit_workspaces, s.workspace_id) THEN s.list_usd END) AS a_list_usd,
         sum(CASE WHEN array_contains(u.audit_workspaces, s.workspace_id) THEN s.net_usd END) AS a_net_usd,
         max(st.tables) AS stored_tables, max(st.tib) AS stored_tib
  FROM spend s
  FULL OUTER JOIN q ON s.workspace_id = q.workspace_id
  CROSS JOIN users u
  CROSS JOIN win w
  CROSS JOIN stored st
)
SELECT inline(array(
  named_struct('metric', 'Cost per query', 'kind', 'kpi', 'value', concat('$', format_number(m.q_net_usd / m.queries, 4)),
               'coverage', concat(format_number(100 * m.q_list_usd / m.list_usd, 1), '% of spend'), 'definition', 'Spend of the workspaces with finished queries / those queries',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'Cost per MAU, all identities', 'kind', 'kpi', 'value', concat('$', format_number(m.a_net_usd / m.mau, 2)),
               'coverage', concat(format_number(100 * m.a_list_usd / m.list_usd, 1), '% of spend'), 'definition', 'Spend of the workspaces in the audit log / monthly active identities, people and service principals',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'Cost per MAU, humans', 'kind', 'kpi', 'value', concat('$', format_number(m.a_net_usd / m.mau_human, 2)),
               'coverage', concat(format_number(100 * m.a_list_usd / m.list_usd, 1), '% of spend'), 'definition', 'Spend of the workspaces in the audit log / monthly active people, the audit identities that are emails',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'Cost per TiB of data under management', 'kind', 'kpi', 'value', CASE WHEN m.stored_tib > 0 THEN concat('$', format_number(m.a_net_usd / m.stored_tib, 2)) ELSE '' END,
               'coverage', CASE WHEN m.stored_tib IS NULL THEN 'needs system.storage.table_metrics_history' ELSE concat(concat(format_number(100 * m.a_list_usd / m.list_usd, 1), '% of spend'), ' · ', concat(format_number(m.stored_tables, 0), ' tables')) END, 'definition', 'Spend of the workspaces in the audit log / TiB of active table data in this metastore',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'Window', 'kind', 'input', 'value', concat(m.start_date, ' to ', m.end_date),
               'coverage', '', 'definition', '28 full days, ending on the newest day whose billing has finished landing',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'Total spend', 'kind', 'input', 'value', concat('$', format_number(m.net_usd, 0)),
               'coverage', concat(format_number(m.workspaces, 0), ' workspaces'), 'definition', 'Usage × price, every workspace',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'Effective discount', 'kind', 'input', 'value', CASE WHEN m.priced_list_usd IS NULL THEN '' ELSE concat(format_number(100 * (1 - m.priced_acct_usd / m.priced_list_usd), 1), '%', CASE WHEN m.unpriced_rows > 0 THEN ' (partial)' ELSE '' END) END,
               'coverage', concat(format_number(100 * coalesce(m.priced_list_usd, 0) / m.list_usd, 1), '% of list spend priced'), 'definition', '1 - account $ / list $, on priced SKUs',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'Avg daily spend, last 7 days', 'kind', 'input', 'value', concat('$', format_number(m.daily_net_usd, 0)),
               'coverage', '', 'definition', 'Spend in the last 7 days of the window / 7',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'Active products', 'kind', 'input', 'value', concat(format_number(m.products, 0), ''),
               'coverage', '', 'definition', 'Billing products with spend',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'MAU, all identities (approx)', 'kind', 'input', 'value', concat(format_number(m.mau, 0), ''),
               'coverage', concat(format_number(m.a_workspaces, 0), ' workspaces in audit'), 'definition', 'Distinct audit identities, 28 days',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'MAU, humans (approx)', 'kind', 'input', 'value', concat(format_number(m.mau_human, 0), ''),
               'coverage', concat(format_number(m.a_workspaces, 0), ' workspaces in audit'), 'definition', 'Audit identities that are emails',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'WAU (approx)', 'kind', 'input', 'value', concat(format_number(m.wau, 0), ''),
               'coverage', '', 'definition', 'Distinct audit identities, last 7 days',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'DAU (approx)', 'kind', 'input', 'value', concat(format_number(m.dau, 0), ''),
               'coverage', '', 'definition', 'Distinct audit identities, last day',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'Finished queries', 'kind', 'input', 'value', concat(format_number(m.queries, 0), ''),
               'coverage', concat(format_number(m.q_workspaces, 0), ' workspaces with queries'), 'definition', 'query.history rows, status FINISHED',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'Data read', 'kind', 'input', 'value', concat(format_number(m.read_tib, 0), ' TiB'),
               'coverage', '', 'definition', 'read_bytes of finished queries',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'DBSQL queries', 'kind', 'input', 'value', concat(format_number(m.sql_queries, 0), ''),
               'coverage', concat(format_number(m.sql_workspaces, 0), ' workspaces with DBSQL'), 'definition', 'Finished queries on a SQL warehouse',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'DBSQL data read', 'kind', 'input', 'value', concat(format_number(m.sql_read_tib, 0), ' TiB'),
               'coverage', '', 'definition', 'read_bytes of those queries',
               'has_account_prices', m.priced_list_usd IS NOT NULL),
  named_struct('metric', 'Data under management', 'kind', 'input', 'value', CASE WHEN m.stored_tib IS NULL THEN '' ELSE concat(format_number(m.stored_tib, 0), ' TiB') END,
               'coverage', CASE WHEN m.stored_tib IS NULL THEN 'needs system.storage.table_metrics_history' ELSE concat(format_number(m.stored_tables, 0), ' tables') END, 'definition', 'Active table data, each table at its newest snapshot in the window',
               'has_account_prices', m.priced_list_usd IS NOT NULL)
)) FROM m
```

If the account can't read `system.storage.table_metrics_history`, replace the `stored` CTE with `SELECT CAST(NULL AS BIGINT) AS tables, CAST(NULL AS DOUBLE) AS tib` and leave the data-under-management figures out.

### Query 2. Weekly unit costs (12 weeks)

Cost per query, per TiB of data under management and per weekly active user, one 7-day bucket at a time, ending where the table above ends. A unit cost jumping above its own normal means the same work got pricier.

Weekly buckets do not overlap, so a jump shows in full in the week it happens. The user ratio uses weekly active users for that reason: a rolling monthly count would spread one bad week across four. The data-under-management line starts when system.storage.table_metrics_history starts.

```sql
WITH latest AS (   -- the newest ingestion day; billing is still writing to it
  SELECT max(ingestion_date) AS day FROM system.billing.usage WHERE usage_date >= current_date() - INTERVAL 7 DAYS
),
newest AS (   -- the usage day before it: full once its usage runs to midnight and its next-day records have landed
  SELECT max(u.usage_end_time) AS last_end, count(CASE WHEN u.ingestion_date = l.day THEN 1 END) AS next_day_records
  FROM system.billing.usage u CROSS JOIN latest l
  WHERE u.usage_date = (SELECT date_sub(day, 1) FROM latest)
),
bounds AS (
  SELECT CASE WHEN n.last_end >= l.day AND n.next_day_records > 0 THEN date_sub(l.day, 1)
              ELSE date_sub(l.day, 2) END AS end_date
  FROM latest l CROSS JOIN newest n
),
win AS (SELECT date_sub(end_date, 83) AS start_date, end_date FROM bounds),
account_prices AS (
  SELECT sku_name, cloud, currency_code, usage_unit, price_start_time, price_end_time,
         pricing.default AS unit_price
  FROM system.billing.account_prices
),
priced AS (
  SELECT u.workspace_id, u.billing_origin_product AS product,
         datediff(w.end_date, u.usage_date) AS days_back,
         u.product_features.is_serverless AS is_serverless,
         u.product_features.sql_tier AS sql_tier,
         u.usage_quantity * lp.pricing.effective_list.default AS list_usd,
         u.usage_quantity * ap.unit_price AS acct_usd
  FROM system.billing.usage u
  CROSS JOIN win w
  LEFT JOIN system.billing.list_prices lp
    ON u.sku_name = lp.sku_name AND u.cloud = lp.cloud AND u.usage_unit = lp.usage_unit
   AND u.usage_start_time >= lp.price_start_time
   AND (lp.price_end_time IS NULL OR u.usage_start_time < lp.price_end_time)
  LEFT JOIN account_prices ap
    ON u.sku_name = ap.sku_name AND u.cloud = ap.cloud AND u.usage_unit = ap.usage_unit
   AND ap.currency_code = lp.currency_code
   AND u.usage_start_time >= ap.price_start_time
   AND (ap.price_end_time IS NULL OR u.usage_start_time < ap.price_end_time)
  WHERE u.usage_date BETWEEN (SELECT start_date FROM win) AND (SELECT end_date FROM win)
),
queries AS (   -- finished queries per workspace and day; read_bytes summed as DOUBLE (the BIGINT sum overflows)
  SELECT q.workspace_id, datediff(w.end_date, to_date(q.start_time)) AS days_back,
         count(*) AS queries, sum(CAST(q.read_bytes AS DOUBLE)) AS read_bytes,
         count(q.compute.warehouse_id) AS sql_queries,
         sum(CASE WHEN q.compute.warehouse_id IS NOT NULL THEN CAST(q.read_bytes AS DOUBLE) END) AS sql_read_bytes
  FROM system.query.history q CROSS JOIN win w
  WHERE q.execution_status = 'FINISHED'
    AND q.start_time >= (SELECT start_date FROM win) AND q.start_time < (SELECT date_add(end_date, 1) FROM win)
  GROUP BY 1, 2
),
ids AS (   -- each audit identity once per workspace and day; an email is a person, a UUID a service principal
  SELECT a.workspace_id, datediff(w.end_date, a.event_date) AS days_back, a.user_identity.email AS identity
  FROM system.access.audit a CROSS JOIN win w
  WHERE a.event_date BETWEEN (SELECT start_date FROM win) AND (SELECT end_date FROM win)
    AND a.user_identity.email IS NOT NULL
  GROUP BY 1, 2, 3
),
stored AS (   -- per week, each table at its newest snapshot in the week, unless dropped by the week's end
  SELECT wk, sum(active_bytes) / POW(1024, 4) AS tib
  FROM (SELECT floor(datediff(w.end_date, t.snapshot_date) / 7) AS wk, t.active_bytes, t.table_dropped_time,
               w.end_date
        FROM system.storage.table_metrics_history t CROSS JOIN win w
        WHERE t.snapshot_date BETWEEN (SELECT start_date FROM win) AND (SELECT end_date FROM win)
        QUALIFY row_number() OVER (PARTITION BY floor(datediff(w.end_date, t.snapshot_date) / 7), t.table_id
                                   ORDER BY t.snapshot_date DESC) = 1)
  WHERE table_dropped_time IS NULL OR to_date(table_dropped_time) > date_sub(end_date, CAST(wk AS INT) * 7)
  GROUP BY wk
),
spend AS (SELECT workspace_id, floor(days_back / 7) AS wk, sum(coalesce(acct_usd, list_usd)) AS usd
          FROM priced GROUP BY 1, 2),
q AS (SELECT workspace_id, floor(days_back / 7) AS wk, sum(queries) AS queries FROM queries GROUP BY 1, 2),
users AS (SELECT floor(days_back / 7) AS wk, approx_count_distinct(identity) AS wau,
                 collect_set(workspace_id) AS audit_workspaces
          FROM ids GROUP BY 1)
SELECT date_sub(max(w.end_date), CAST(s.wk AS INT) * 7) AS week,
       round(sum(CASE WHEN q.queries > 0 THEN s.usd END) / sum(q.queries), 4) AS `cost per query`,
       round(sum(CASE WHEN array_contains(u.audit_workspaces, s.workspace_id) THEN s.usd END)
             / nullif(max(st.tib), 0), 2) AS `cost per TiB under management`,
       round(sum(CASE WHEN array_contains(u.audit_workspaces, s.workspace_id) THEN s.usd END) / max(u.wau), 2)
         AS `cost per weekly active user`
FROM spend s
LEFT JOIN q ON s.workspace_id = q.workspace_id AND s.wk = q.wk
LEFT JOIN users u ON s.wk = u.wk
LEFT JOIN stored st ON s.wk = st.wk
CROSS JOIN win w
GROUP BY s.wk ORDER BY week
```

If the account can't read `system.storage.table_metrics_history`, replace the `stored` CTE with `SELECT CAST(NULL AS DOUBLE) AS wk, CAST(NULL AS DOUBLE) AS tib` and leave the data-under-management figures out.

### Query 3. Spend by product (28 days)

Spend per billing product with its share of the total, at your account prices where they exist and list price otherwise.

```sql
WITH latest AS (   -- the newest ingestion day; billing is still writing to it
  SELECT max(ingestion_date) AS day FROM system.billing.usage WHERE usage_date >= current_date() - INTERVAL 7 DAYS

),

account_prices AS (

         datediff(w.end_date, u.usage_date) AS days_back,
         u.product_features.is_serverless AS is_serverless,
         u.product_features.sql_tier AS sql_tier,
         u.usage_quantity * lp.pricing.effective_list.default AS list_usd,
         u.usage_quantity * ap.unit_price AS acct_usd
  FROM system.billing.usage u

    ON u.sku_name = lp.sku_name AND u.cloud = lp.cloud AND u.usage_unit = lp.usage_unit
   AND u.usage_start_time >= lp.price_start_time
   AND (lp.price_end_time IS NULL OR u.usage_start_time < lp.price_end_time)
  LEFT JOIN account_prices ap
    ON u.sku_name = ap.sku_name AND u.cloud = ap.cloud AND u.usage_unit = ap.usage_unit
   AND ap.currency_code = lp.currency_code
   AND u.usage_start_time >= ap.price_start_time
   AND (ap.price_end_time IS NULL OR u.usage_start_time < ap.price_end_time)
  WHERE u.usage_date BETWEEN (SELECT start_date FROM win) AND (SELECT end_date FROM win)
)
SELECT product AS product,
       round(sum(coalesce(acct_usd, list_usd)), 2) AS spend_usd,
       round(100 * sum(coalesce(acct_usd, list_usd)) / sum(sum(coalesce(acct_usd, list_usd))) OVER (), 1) AS pct_of_total
FROM priced 
GROUP BY 1 HAVING sum(coalesce(acct_usd, list_usd)) > 0
ORDER BY spend_usd DESC
```

### Query 4. Serverless vs classic (28 days)

How much of the spend runs on serverless compute, from the billing record's own is_serverless flag. Model Serving, Vector Search, Lakebase, storage and networking rows mostly carry no flag, so they get their own bar instead of a guess.

```sql
WITH latest AS (   -- the newest ingestion day; billing is still writing to it
  SELECT max(ingestion_date) AS day FROM system.billing.usage WHERE usage_date >= current_date() - INTERVAL 7 DAYS
),
newest AS (   -- the usage day before it: full once its usage runs to midnight and its next-day records have landed
  SELECT max(u.usage_end_time) AS last_end, count(CASE WHEN u.ingestion_date = l.day THEN 1 END) AS next_day_records
  FROM system.billing.usage u CROSS JOIN latest l
  WHERE u.usage_date = (SELECT date_sub(day, 1) FROM latest)
),
bounds AS (
  SELECT CASE WHEN n.last_end >= l.day AND n.next_day_records > 0 THEN date_sub(l.day, 1)
              ELSE date_sub(l.day, 2) END AS end_date
  FROM latest l CROSS JOIN newest n
),
win AS (SELECT date_sub(end_date, 27) AS start_date, end_date FROM bounds),
account_prices AS (
  SELECT sku_name, cloud, currency_code, usage_unit, price_start_time, price_end_time,
         pricing.default AS unit_price
  FROM system.billing.account_prices
),
priced AS (
  SELECT u.workspace_id, u.billing_origin_product AS product,
         datediff(w.end_date, u.usage_date) AS days_back,
         u.product_features.is_serverless AS is_serverless,
         u.product_features.sql_tier AS sql_tier,
         u.usage_quantity * lp.pricing.effective_list.default AS list_usd,
         u.usage_quantity * ap.unit_price AS acct_usd
  FROM system.billing.usage u
  CROSS JOIN win w
  LEFT JOIN system.billing.list_prices lp
    ON u.sku_name = lp.sku_name AND u.cloud = lp.cloud AND u.usage_unit = lp.usage_unit
   AND u.usage_start_time >= lp.price_start_time
   AND (lp.price_end_time IS NULL OR u.usage_start_time < lp.price_end_time)
  LEFT JOIN account_prices ap
    ON u.sku_name = ap.sku_name AND u.cloud = ap.cloud AND u.usage_unit = ap.usage_unit
   AND ap.currency_code = lp.currency_code
   AND u.usage_start_time >= ap.price_start_time
   AND (ap.price_end_time IS NULL OR u.usage_start_time < ap.price_end_time)
  WHERE u.usage_date BETWEEN (SELECT start_date FROM win) AND (SELECT end_date FROM win)
)
SELECT CASE WHEN is_serverless THEN 'Serverless' WHEN NOT is_serverless THEN 'Classic' ELSE 'Not flagged in billing' END AS compute,
       round(sum(coalesce(acct_usd, list_usd)), 2) AS spend_usd,
       round(100 * sum(coalesce(acct_usd, list_usd)) / sum(sum(coalesce(acct_usd, list_usd))) OVER (), 1) AS pct_of_total
FROM priced 
GROUP BY 1 HAVING sum(coalesce(acct_usd, list_usd)) > 0
ORDER BY spend_usd DESC
```

### Query 5. DBSQL spend by warehouse tier (28 days)

SQL warehouse spend by tier. Billing leaves sql_tier empty on serverless warehouses, so serverless is read from is_serverless.

```sql
WITH latest AS (   -- the newest ingestion day; billing is still writing to it
  SELECT max(ingestion_date) AS day FROM system.billing.usage WHERE usage_date >= current_date() - INTERVAL 7 DAYS
),
newest AS (   -- the usage day before it: full once its usage runs to midnight and its next-day records have landed
  SELECT max(u.usage_end_time) AS last_end, count(CASE WHEN u.ingestion_date = l.day THEN 1 END) AS next_day_records
  FROM system.billing.usage u CROSS JOIN latest l
  WHERE u.usage_date = (SELECT date_sub(day, 1) FROM latest)
),
bounds AS (
  SELECT CASE WHEN n.last_end >= l.day AND n.next_day_records > 0 THEN date_sub(l.day, 1)
              ELSE date_sub(l.day, 2) END AS end_date
  FROM latest l CROSS JOIN newest n
),
win AS (SELECT date_sub(end_date, 27) AS start_date, end_date FROM bounds),
account_prices AS (
  SELECT sku_name, cloud, currency_code, usage_unit, price_start_time, price_end_time,
         pricing.default AS unit_price
  FROM system.billing.account_prices
),
priced AS (
  SELECT u.workspace_id, u.billing_origin_product AS product,
         datediff(w.end_date, u.usage_date) AS days_back,
         u.product_features.is_serverless AS is_serverless,
         u.product_features.sql_tier AS sql_tier,
         u.usage_quantity * lp.pricing.effective_list.default AS list_usd,
         u.usage_quantity * ap.unit_price AS acct_usd
  FROM system.billing.usage u
  CROSS JOIN win w
  LEFT JOIN system.billing.list_prices lp
    ON u.sku_name = lp.sku_name AND u.cloud = lp.cloud AND u.usage_unit = lp.usage_unit
   AND u.usage_start_time >= lp.price_start_time
   AND (lp.price_end_time IS NULL OR u.usage_start_time < lp.price_end_time)
  LEFT JOIN account_prices ap
    ON u.sku_name = ap.sku_name AND u.cloud = ap.cloud AND u.usage_unit = ap.usage_unit
   AND ap.currency_code = lp.currency_code
   AND u.usage_start_time >= ap.price_start_time
   AND (ap.price_end_time IS NULL OR u.usage_start_time < ap.price_end_time)
  WHERE u.usage_date BETWEEN (SELECT start_date FROM win) AND (SELECT end_date FROM win)
)
SELECT CASE WHEN is_serverless THEN 'SERVERLESS' ELSE coalesce(sql_tier, 'UNKNOWN') END AS sql_tier,
       round(sum(coalesce(acct_usd, list_usd)), 2) AS spend_usd,
       round(100 * sum(coalesce(acct_usd, list_usd)) / sum(sum(coalesce(acct_usd, list_usd))) OVER (), 1) AS pct_of_sql_spend
FROM priced WHERE product = 'SQL'
GROUP BY 1 HAVING sum(coalesce(acct_usd, list_usd)) > 0
ORDER BY spend_usd DESC
```

## Step 3. Read the derived metrics

Query 1 returns these rows already computed. `kind` is kpi for the headline unit costs and input for the raw inputs. `value` uses the account's price where one is set and list price otherwise, and `coverage` is the share of spend the ratio rests on.

| Metric | Formula |
|---|---|
| Cost per query | Spend of the workspaces with finished queries / those queries |
| Cost per MAU, all identities | Spend of the workspaces in the audit log / monthly active identities, people and service principals |
| Cost per MAU, humans | Spend of the workspaces in the audit log / monthly active people, the audit identities that are emails |
| Cost per TiB of data under management | Spend of the workspaces in the audit log / TiB of active table data in this metastore |
| Effective discount | 1 - account $ / list $, on priced SKUs |

Raw inputs in the same table:

- Window: 28 full days, ending on the newest day whose billing has finished landing.
- Total spend: Usage × price, every workspace.
- Avg daily spend, last 7 days: Spend in the last 7 days of the window / 7.
- Active products: Billing products with spend.
- MAU, all identities (approx): Distinct audit identities, 28 days.
- MAU, humans (approx): Audit identities that are emails.
- WAU (approx): Distinct audit identities, last 7 days.
- DAU (approx): Distinct audit identities, last day.
- Finished queries: query.history rows, status FINISHED.
- Data read: read_bytes of finished queries.
- DBSQL queries: Finished queries on a SQL warehouse.
- DBSQL data read: read_bytes of those queries.
- Data under management: Active table data, each table at its newest snapshot in the window.

What the workspace sets mean:

- Query-workspace spend is the spend of workspaces with at least one finished query in `system.query.history` in the window.
- Audit-workspace spend is the spend of workspaces with at least one event in `system.access.audit` in the window.
- Data under management is active table data from `system.storage.table_metrics_history`, each table at its newest snapshot in the window unless it was dropped by the window's end. It lists the tables in the current region's metastore, like the audit log, so the ratio divides the spend of the workspaces in the audit log.

## Caveats

- Billing covers every workspace in the account. Query history and audit list fewer (they are regional and only hold workspaces with activity), so each ratio divides only the spend of the workspaces its denominator can see. Always quote a ratio with its coverage.
- User counts use `approx_count_distinct`, so say approx. An identity with an email is a person; a UUID is a service principal.
- Each figure uses the account price where `system.billing.account_prices` has one for the SKU and list price otherwise, so no discount is ever invented. With no account prices every figure is at list price and the effective discount has nothing to show; with prices for only some SKUs it is marked partial. Account prices in a currency other than the list price's are not compared.
- `system.storage.table_metrics_history` is new. Where its history starts inside the trend's twelve weeks, the data-under-management line starts with it.
- Sum `read_bytes` as DOUBLE; the BIGINT sum overflows on large accounts.
